# Hanaparttime 독립 운영 배포

이 브랜치는 웹 화면, API, D1, R2를 본인 Cloudflare 계정에 직접 배포한다.
실행 중 ChatGPT Sites/Vercel/Supabase를 호출하지 않는다. OCR 엔진과 한국어·영어 모델도 같은 사이트에서 제공한다.

## 확인된 상태

- 독립 관리자 인증과 기존 기능을 로컬 D1/R2 통합 테스트로 검증했다.
- 2026-09-17 본인 Cloudflare 계정에 D1·비공개 R2·Worker 배포 완료: https://hanaparttime.isacc7224.workers.dev
- 사용 한도: 합계 8GB, 최근 32일 쓰기 5만 회·읽기 50만 회. 앱 사용 제한이며 계정 전체의 과금 차단은 아니다.
- 실제 주소에서 독립된 로그인 세션 2개, 5,763,023바이트 PNG 업로드·다운로드, ZIP CRC·SHA-256, 일일보고와 저장량 복구를 확인했다. 검증용 사진은 삭제했다.
- 로컬 관리 키와 최초 공용 로그인 정보는 `.deploy-secrets/`에 저장하며 Git에서 제외된다.
- 기존 사이트의 실제 사진·비고·진행 상태 이전과 실물 휴대폰 검증은 아직 수행하지 않았다.
- 기존 운영 사이트는 변경하거나 삭제하지 않았다.

## 계정 연결 후 배포

1. Node.js 22.13 이상에서 기존 잠금 파일로 패키지를 설치한다.
2. `node node_modules/wrangler/bin/wrangler.js login`으로 본인 계정에 연결한다.
3. `node node_modules/wrangler/bin/wrangler.js d1 create hanaparttime-db --location apac`으로 데이터베이스를 만든다.
4. `node node_modules/wrangler/bin/wrangler.js r2 bucket create hanaparttime-photos --location apac`으로 비공개 사진 버킷을 만든다. 공개 버킷 접근은 켜지 않는다.
5. `cloudflare/deployment.example.json`을 `cloudflare/deployment.json`으로 복사하고 실제 계정 ID와 D1 ID를 넣는다. 이 파일은 Git에서 제외된다.
6. `npm run deploy:production`을 실행한다. 빌드, 타입 검사, 통합 테스트 후 DB 마이그레이션과 Workers 배포를 순서대로 수행한다. 로컬 검증만 하려면 `npm run deploy:production -- --check`를 사용한다.
7. 출력된 `https://hanaparttime.<계정 하위 도메인>.workers.dev`에서 `/account/setup`을 열고 생성된 관리 키로 공용 아이디/비밀번호를 설정한다. 관리 키는 `.deploy-secrets/production.json`에만 저장하며 일반 사용자에게 공유하지 않는다.
8. 실제 새 URL에서 로그아웃 상태 접근 차단, 두 기기의 공용 로그인, 5MB 이상의 사진 원본 업로드·다운로드, ZIP 및 일일보고를 확인한다. 관리자 암호 변경 시 기존 세션도 폐기된다.

`hanaparttime.com` 같은 도메인은 별도 소유권과 구매가 필요하다. 위 workers.dev 주소는 계정 하위 도메인이 결정된 후 확정된다.

## 기존 자료 이전

먼저 기존 사이트에서 전체 ZIP을 내려받고 `/api/library`의 일정·비고·진행 상태와 각 폴더의 사진 목록을 인증된 세션으로 백업한다. 사진만 ZIP에 담겨 있으므로 ZIP만으로 비고와 상태를 복원했다고 간주하면 안 된다.

대상 DB에는 일정 ID, 지역·날짜, 번지·호수, 연락처, 일정 메모, 비고, 상태를 함께 옮긴다. R2 원본을 복사하고 원본의 바이트 수와 SHA-256을 대조한 뒤 사진 메타데이터를 기록한다. 일정표 원본도 전체 ZIP에서 별도로 복원한다. 원본 파일 이름이 같아도 사진 ID는 유지하고, 대상 기존 데이터를 덮어쓰지 않는다.

기존 로그인 세션과 로그인 시도 기록은 이전하지 않는다. 데이터 소유자 값은 새 `site_account.owner`와 일치하도록 설정해야 한다. 이전 전후 지역·날짜·폴더 수, 원본 사진 수·크기·해시, 비고·상태를 모두 확인한 후 사용 주소를 전환한다. 기존 자료는 검증 완료 전 삭제하지 않는다.

## 비용과 제한

### 앱에서 적용하는 사용 제한

- 사진과 일정표 원본을 합쳐 8,000,000,000바이트(십진 8GB)까지 저장한다.
- 최근 32개 UTC 날짜 동안 R2 쓰기 50,000회, 읽기 500,000회까지만 허용한다. 월초에 즉시 초기화하지 않으므로 청구 주기 경계에도 여유를 둔다.
- 미리보기·원본 다운로드는 각각 읽기를 사용하고, ZIP은 포함하는 원본 파일 수만큼 시작 전에 읽기를 예약한다. 한도가 부족하면 ZIP 응답을 시작하지 않고 429 안내를 반환한다.
- ZIP은 브라우저에서 생성한다. `/api/export`는 파일 경로·크기와 1시간 유효한 일회용 다운로드 목록(JSON)을 반환한다. `/api/export/<token>`은 현재 로그인·소유자·세션 버전을 확인한 후 예약된 원본 한 개를 전달하며 토큰은 재사용할 수 없다. 이 경로는 `cloudflare/worker.ts`에서 R2 스트림을 직접 반환해 무료 Worker의 대용량 파일 처리 CPU를 줄인다.
- PC Chrome·Edge에서는 저장 위치를 선택하고 ZIP을 디스크에 스트리밍한다. 해당 기능이 없는 브라우저는 완성된 ZIP을 다운로드하며 256MB까지 지원한다. 더 큰 범위는 폴더별로 나누거나 PC Chrome·Edge를 사용한다. 다운로드 중 이 화면을 유지해야 하며, 누락·크기 불일치·취소 시 불완전한 ZIP 저장을 중단한다.
- 업로드 전에 D1에서 용량을 원자적으로 예약한다. 동시에 올린 요청, 일정표 사진, 실패 후 정리가 확인되지 않은 파일도 용량에 포함한다. 삭제가 R2에서 확인된 뒤에만 용량을 돌려준다. 실패·취소 요청의 작업 횟수는 돌려주지 않는다.
- 한도 도달 시 해당 기능만 차단하며 기존 자료를 자동 삭제하지 않는다. D1 사용량 기록에 실패하면 R2 읽기·쓰기도 진행하지 않는다. 로그인한 보관함 화면에서 사용량을 볼 수 있다.
- **Cloudflare 계정 전체의 과금 상한이 아니다.** 다른 버킷, 대시보드·S3 도구·다른 Worker의 직접 접근, 적용 전 요청, 메타데이터에 없는 기존 객체는 이 집계 밖이다. 전용 비공개 Standard 버킷에만 적용하고 공개 URL·별도 쓰기 경로를 활성화하지 않는다. 기존 데이터를 외부 도구로 이전할 때에는 객체별 사용량 원장도 대조해야 한다.
- 용량 예약은 안전을 위해 과다 집계될 수 있다. 실패한 업로드의 고아 객체·원장을 자동 삭제하거나 원장만 초기화하지 말고, 실제 R2 객체와 대조한 뒤 정리한다.

2026-09-17 PC 검증: Windows 경로를 지원하도록 통합 테스트를 수정했다. 테스트 실행 시 Python 디렉터리를 프로세스 PATH에 추가하고 `PYTHONIOENCODING=utf-8`을 설정한다. `node --test tests/r2-budget.test.mjs`는 실제 Miniflare D1/R2에서 동시성·기간 경계·실패 복구를 검증한다. `npm run deploy:production -- --check`는 빌드·타입 검사·전체 저장 통합 테스트·배포 사전 검사를 실행한다.

**이 변경 이후에는 project의 소스를 빌드해 배포한다.** 상위 `deploy/` 폴더의 예전 빌드에는 사용량 제한이 없으므로 그 파일로 재배포하지 않는다.

무료 범위를 목표로 하고 요금제 업그레이드는 하지 않는다. Cloudflare Workers Free는 일 10만 요청과 요청당 10ms CPU 제한이 있으며, R2 Standard는 월 10GB-month 저장량, Class A 100만 회·Class B 1천만 회 무료 범위를 제공한다. R2는 무료량을 넘으면 과금될 수 있고 활성화 시 결제 수단을 요구할 수 있다. 이 단계가 나오면 사용자 설정이 필요하다. 대규모 ZIP의 CPU 사용량은 실제 계정에서 확인해야 한다.

- https://developers.cloudflare.com/workers/platform/pricing/
- https://developers.cloudflare.com/r2/pricing/

배포 스크립트는 계정 ID 확인 없이 배포하지 않으며, 요금제 변경·결제 수단 등록·이전 사이트 삭제를 수행하지 않는다.

2026-09-17 ZIP 운영 검증: 폴더 사진 29장(93,749,953바이트), 전체 사진·일정표 31개(94,272,969바이트)를 내려받아 ZIP CRC와 개별 원본 SHA-256을 모두 대조했다. 실제 브라우저의 전체 다운로드 버튼으로 생성한 ZIP도 동일 SHA-256을 확인했다(파일 저장 API 없는 브라우저 경로). 운영 ZIP 원본 전달은 CPU 1~4ms로 정상 완료됐다. PC 네이티브 저장 대화상자 조작은 자동화 검증 범위 밖이며 스트림의 정상 완료·오류·취소는 테스트로 검증했다.
