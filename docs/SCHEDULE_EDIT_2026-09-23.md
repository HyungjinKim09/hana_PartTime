- 기존 일정과 지역·날짜·번지·호수가 겹치는 수정은 차단하며, 다른 폴더에 자료를 합치지 않습니다.

- 사진 전송 중이거나 미저장 조사 비고·촬영 사진이 있으면 수정 시작을 막습니다. 수정 폼을 닫을 때 미저장 내용을 확인하고, 저장 중에는 중복 제출과 닫기를 막습니다.
- 좁은 화면에서는 입력란이 한 열로 표시되고 취소·저장 버튼이 하단에 유지됩니다.
