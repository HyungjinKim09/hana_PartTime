## 2026-10-10 원본 비교 수정 및 실제 검증

이번 변경은 로컬에만 적용했다. 배포·Git 커밋·푸시는 하지 않았고 기존 인증·일정표 작업은 보존했다. 아래 이전 기록의 하네스와 미검증 상태는 이번 실제 사이트 검증으로 갱신됐다.

### 수정

- 작은 창고 벽의 조각을 OCR 글자 상자로 제거하기 전에 관측된 선부터 합친다. 부분 겹침은 사진 기울기를 허용하지만 가까운 별도 평행 벽은 유지한다. 빈 간격을 합칠 때는 실제 픽셀 근거를 요구한다.
- 치수 글자와 같은 축에 있던 벽 끝을 실제 교점에서 잘라 짧은 돌출을 제거한다. 글자 획을 교점으로 오해하지 않고 작은 창고의 연결된 구분선을 보호한다. 15° 이내 직각 보정과 명확한 대각선 유지도 그대로다.
- 글자 위치와 추출된 선 방향을 실제 픽셀 좌표에서 비교해 가로 합계의 세로 단차, 반대쪽 치수의 중복 합계를 제외한다. 빠진 세로 근거는 바깥쪽의 실제 전체 높이 외곽 옆 숫자로만 복원한다. 숫자 자체는 사진에 적힌 값에서만 가져온다. 중복 위치·충돌·모호한 경우는 보류한다.
- 메타데이터는 최대 1600px, 방향은 최대 960px JPEG로 읽는다. 모델은 기존 Cloudflare `@cf/google/gemma-4-26b-a4b-it`다. 일정표 CLOVA 경로는 변경하지 않았다. 현재 비교 자료는 960×720이므로 고해상도 입력 개선 효과까지 입증한 것은 아니다.
- 불확실한 글자는 해당 상자를 확대하여 번호가 붙은 한 장의 이미지로 재확인한다. 확실한 글자만 교체하며 위치·상자·치수는 유지한다. 불확실하면 기존 글자를 유지하고 새 후보도 먼저 안내한다. 일반적인 ‘방향’ 경고가 ‘방’ 재확인을 유발하는 오매칭을 막았다.
- 자동 인식은 방향·메타데이터·선택적 글자 확인으로 최대 3회 AI 요청을 사용한다. 기존 인증·도면 소유권 검사·하루 20회 원자적 제한을 공유한다. 서비스 실패 시 기존 초안을 유지한다.
- 별도 module Worker를 Vite worker import로 빌드하여 브라우저의 file URL 로딩 오류를 수정했다. 데스크톱에서 도면 종류를 선택하면 사진 탭이 조사 정보 탭으로 돌아가던 상태 초기화도 분리했다.

### 실제 결과와 범위

기존 제공 사진을 보존한 960×720 자료로 실제 사이트의 새 AI 응답을 확인했다. API mock이나 미리 만든 정답을 화면에 넣지 않았다. 초기 응답의 ‘침방’ 오독과 잘못된 합계를 확인하고 수정 후 다시 실행했다.

- 새 화면에서 주방·창고·W.C·방·거실·현관·베란다를 확인했다. 전체 가로 `1.0 + 10.3 + 1.1 = 12.4m`, 전체 세로 `6.7m`로 표시·저장했다.
- 새 AI 응답의 세로 `5.3 + 6.7`을 반대쪽 숫자로 판별해 거부하고 실제 전체 높이 옆 `6.7`을 선택했다. 이전 응답의 가로 `4.4 + 1.4 + 5.9`에 섞인 세로 단차 `1.4`도 회귀 자료에서 제외했다.
- 실제 저장 초안은 선 24개(실선 6, 점선 18), 글자 19개다. 원본에 수기로 표시한 선 24개와 10px 이내 거리·90% 초과 구간 커버리지로 비교해 24개 모두 포함, 추가 오검출 0개였다. 이 사진의 결과이며 일반적인 인식률 수치가 아니다.
- 별도의 실제 확대 API는 ‘주방’을 읽었지만 `uncertain: true`로 판정했다. 이런 결과를 확실한 답처럼 덮어쓰지 않는다. 모든 흐린 손글자를 자동으로 고친다는 보장은 없다.
- 도면을 저장하고 다시 열어 치수·선·글자가 유지되는 것을 확인했다. 동일 저장 초안으로 생성한 VSDX의 ZIP CRC, 전체 XML, 선·글자 수, 실선·점선, 직각, 전체 12.4×6.7m 범위를 독립 Python 검사로 확인했다. Microsoft Visio 데스크톱에서 직접 연 검증은 아니다. UI에서 다운로드 요청 안내는 확인했지만 자동화 도구로 완료 파일 경로를 얻지 못했다.

전체 치수는 수기로 수정할 수 있다. 사진 기반 내부 위치는 초안이며 방별 정밀 실측 축척을 보증하지 않는다. 자동 원근 추정과 다양한 모눈·그림자·손글자의 일반 정확도는 추가 검증이 필요하다.

실제 앱은 `http://127.0.0.1:4175`, DB/R2는 `.wrangler/drawing-live-qa`의 로컬 데이터다. AI binding만 원격이다. 빌드 후 `node .sites-runtime/drawing-upgrade/configure.mjs`로 로컬 Wrangler 설정을 재생성하고 기존 persist 경로로 실행한다. `--local`은 원격 AI를 비활성화하므로 추가하지 않는다.

## 방향·치수 자동 인식 추가

사용자가 둘 다 요청하여 자동 인식 버튼을 `방향·치수 자동 인식`으로 변경. 원근 보정 여부와 무관하게 AI 방향 인식을 먼저 수행하고 crop/quad 모서리 순서까지 회전한 다음 원근 보정과 메타데이터 인식 실행. 저장된 source와 보정 원본의 방향 일치 유지.

AI 메타데이터의 dimensionChains는 전체 가로/세로를 덮는 치수 글자의 0-based index 목록. 양쪽 베란다를 포함하는 완전한 구간만 반환하도록 지시. 클라이언트는 글자의 숫자를 읽어 합산하며 중복/읽기 실패/상반된 합계/근거 없음은 null + 확인 경고. 값과 계산식을 화면에 표시하고 수기 수정 유지. 기존 AI widthMeters/heightMeters 추정값만으로는 채우지 않음. AI가 선택한 구간이 실제 전체 범위인지까지 수학적으로 보증하지는 않음.

추가 테스트: 12.4/6.7 합계, 불일치·중복·누락 거부, 90/270도 모서리 회전 복원. 실제 외부 AI 모델의 새 프롬프트 응답 정확도는 아직 미검증. 배포하지 않음.

- 선 분석은 최대 1600px, AI용 이미지는 별도 최대 960px. 무료 OCR 일정표 경로는 변경하지 않음.
- 원근 보정: 사용자가 회전/범위 조정 후 종이의 직사각형 영역을 왼쪽 위부터 시계 방향으로 지정. ㄱ자 건물 외곽을 선택하면 안 됨. 자동 회전 시 지정된 모서리도 함께 회전.
- projective inverse sampling과 양선형 보간. convex/ordered quad 검증, 보정 결과도 최대1600px. source.quad에 저장하며 기존 초안 호환. 원본 겹치기도 저장된 변환으로 재생성.
- 별도 module Worker에서 원근 보정 및 선 추출. 종료/실패/시간초과 정리. 심한 그림자만 제한적으로 밝기 보정. 일반 종이를 하얗게 만드는 실험은 실제 사진의 모눈 오검출 증가로 제외.
- 연결되지 않은 선 끝점은 주황색으로 검토 표시. 누락/정확도 보증이 아님. 도면 실선/점선 편집과 기존 VSDX 유지.
