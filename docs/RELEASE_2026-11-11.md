# 2026-11-11 D1 조회 최적화 및 로그인 요청 보호

선택한 폴더의 사진·조사 인원을 조회할 때 팀 전체 자료를 반복 스캔하던 쿼리를 수정했습니다. 사진 커서와 ZIP 원본 목록의 조회 인덱스를 보완하고, 같은 HTTP 요청의 세션 검증을 공유하며 갱신 시 이전 판정을 폐기합니다. 내 조사 폴더의 중복 집계와 도면만 업로드한 일정의 오포함도 수정했습니다.

로그인·관리자 계정 설정·명시적 토큰 갱신·로그아웃은 Worker 입구에서 native RateLimit 바인딩으로 제한합니다. 차단, 잘못된 메서드/출처, 보호 기능 장애는 D1에 도달하기 전에 응답합니다. 기존 DB 기반 15분 제한은 유지합니다. 로그인 IP별 5회/분 및 공용 10회/분, 갱신·로그아웃 IP별 60회/분 및 공용 120회/분입니다. 공용 카운터는 Cloudflare 지역별 근사 제한이며 전 세계의 엄격한 총량 제한은 아닙니다. 다른 API의 인증 증명 조회와 Workers 자체 요청량을 완전히 없애는 장치도 아닙니다.
