# 사진이 있는 폴더만 ZIP 다운로드

2026-09-23 로컬 구현 후 13:13 KST 운영 반영 완료. 배포 결과는 [운영 배포 기록](RELEASE_ZIP_OCR_2026-09-23.md)을 참고하세요. Git 커밋·push는 아직 수행하지 않았습니다.

- 다운로드 창의 **사진이 있는 폴더만 포함**은 기본으로 켜집니다. 포함·제외할 일정 폴더 수를 표시하며, 해제하면 기존처럼 빈 폴더도 포함합니다.
- 전체·지역·날짜·단일 폴더·주소별 모아보기·200MB 분할 다운로드에 동일하게 적용합니다. 주소별 보기에서는 같은 주소의 여러 날짜를 합친 뒤 실제 사진이 있는 일정만 포함합니다.
- 서버는 요청 범위 내 `kind='photo' AND deleted=0`인 자료를 기준으로 필터링합니다. 도면만 있는 폴더, 삭제된 사진만 있는 폴더, 빈 일정 폴더를 제외합니다. 다운로드 가능한 현장 사진이 없으면 안내하고 티켓을 발급하지 않습니다.
- 폴더명 충돌 처리와 주소 표시명은 필터링 전에 결정하므로 기존 전체/개별 다운로드 경로를 유지합니다. 분할 경계에서 다음 사진의 폴더만 앞 ZIP에 남는 경우도 제거합니다.
- 옵션을 변경하면 이전 분할 목록과 완료 상태를 초기화합니다. 다운로드 중에는 변경할 수 없습니다. 다운로드에 따른 서버 자료 삭제는 없습니다.
