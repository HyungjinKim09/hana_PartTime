# D1 조회 비용 수정

운영 통계에서 조사 인원 집계 SQL 98회가 4,160,062행을 읽었습니다. 같은 날 UTC 기준 전체 5,089,644행 중 약 81.7%입니다. 이번 수정은 API 호출 수와 별개로 SQLite가 실제 읽는 행 수를 줄입니다.

## 변경

- 조사 인원: 선택된 폴더 ID를 먼저 확정하고 인덱스로 사진·활동·개인 조사 기록을 조회합니다. 날짜 요약과 카드에 겹치는 폴더의 증거는 한 번만 읽습니다. 실작업·복원·관리자 지정의 우선순위와 사진 삭제 후 조사 이력을 유지합니다.
- 사진 목록·ZIP 원본 목록: 선택한 폴더에서 조회를 시작하도록 수정했습니다. 활성 사진/종류/시간/ID 인덱스로 커서를 조회하며, 사진 외 자료와 삭제된 사진은 기존 조건대로 제외합니다.
- 세션: 한 HTTP 요청의 자동 로그인 확인·계정 변경 확인·API 인증은 실제 검증 결과를 공유합니다. AsyncLocalStorage의 요청 범위에서 DB와 토큰으로 구분하며 다음 요청에는 재검증합니다. 갱신 성공 시 같은 토큰이라도 이전 만료 판정을 폐기합니다. 클라이언트 헤더를 인증 결과로 신뢰하지 않습니다.
- 내 조사 폴더: 총개수와 현재 페이지가 활동 이력을 두 번 읽지 않도록 집계를 공유하고, 도면만 업로드한 폴더를 현장 조사로 포함하던 오류를 수정했습니다.
- 로그인 제한 정리·R2 사용량 예약: 만료 시각과 종류/날짜 인덱스를 추가했습니다. 서버의 로그인 횟수 제한과 원자적인 무료 사용량 예약은 유지합니다.

## 로컬 측정

실제 Miniflare D1/SQLite에서 제품 함수를 실행해 `meta.rows_read`를 비교했습니다. 시간이나 운영 비용의 보장값이 아닙니다.

| 항목 | 수정 전 | 수정 후 | 조건 |
| --- | ---: | ---: | --- |
| 조사 인원 | 82,923 | 3,305 | 100폴더·3,000사진 중 10폴더·300사진의 날짜 요약+카드 |
| 위 인원 조회에 무관한 사진 3,000장 추가 | — | 3,305 | 다른 날짜/폴더의 자료 증가 |
| 사진 첫 페이지 | 6,031 | 25 | 전체 6,000사진 중 한 폴더의 10사진 |
| 사진 다음 페이지 | — | 26 | 같은 촬영 시각, ID 커서로 중복 방지 |
| 한 폴더 ZIP 사진 목록 | — | 61 | 30사진, 선택 ID 중복 제거 |
| 로그인 제한 만료 정리 | 5,001 | 1 | 유효한 IP/시간 구간 5,000건 |
| R2 읽기 사용량 예약 | 40 | 21 | 300일의 read/write 이력, 최근 32 UTC 날짜 예약 |

테스트는 담당자 출처·소유자/날짜 범위, 사진 페이지/ZIP, 실제 Worker 세션 조회 횟수와 같은 토큰 갱신, 로그아웃/비활성화/암호 변경, 복원 및 기존 기능도 검증합니다.

최종 `node scripts/verify.mjs` 통과: 단위 테스트 159개, 통합 검증 19개 묶음, 타입 검사·빌드, 린트 오류 0개(기존 경고 13개). 독립 코드 리뷰와 갱신 회귀 수정 후 재검토에서 남은 지적 사항은 없습니다. 검증 소스 SHA-256은 `ccd65bd09b943e93c887a18d37b642e4ead1a268ff1271ac87079cc244067936`입니다.

로컬 DB에 0022를 적용하고 4175 서버를 재시작했습니다. 기존 관리자 로그인, 루트 목록, 기존 합성 폴더의 사진 2장·조사 인원 3명, 내 조사 폴더 API의 HTTP 200 응답을 확인했습니다. 원본 사진과 운영 자료는 변경하지 않았습니다.

## 적용과 범위

새 마이그레이션은 `0022_query_indexes.sql`입니다. 운영에는 먼저 미적용 상태인 `0021_folder_operations.sql`, 이어서 `0022`를 적용한 후 Worker를 배포해야 합니다. 인덱스는 저장 공간과 사진 쓰기 비용을 조금 늘리는 대신 반복 조회를 줄입니다. 유료 서비스·새 바인딩·요금제 변경은 없습니다.

현재 수정은 로컬입니다. 운영 무료 D1 조회 한도가 소진된 상태에서 Worker만 먼저 올리지 않습니다. 실제 운영 실행 계획과 조회 감소율은 배포 후 별도로 확인해야 합니다. 선택 범위 안의 사진·활동이 늘면 조사 인원 집계량도 늘어납니다. 이번 패치는 복원/삭제 시 복잡한 무효화가 필요한 영구 요약 테이블 대신, 확인된 팀 전체 스캔과 반복 집계를 제거했습니다. 구역/날짜 목록·주소 검색의 메타데이터 집계와 전체 백업은 요청 범위를 처리하며, 전체 조회가 본래 필요한 작업까지 상수 비용으로 바꾼 것은 아닙니다.
