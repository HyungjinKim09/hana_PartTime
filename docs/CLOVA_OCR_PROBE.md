3. 서버 바인딩 `CLOVA_OCR_URL`, `CLOVA_OCR_SECRET`에 각각 연결한다. 운영 설정 완료. 같은 키로 로컬에서 별도 호출하면 운영 카운터가 알 수 없으므로 별도 로컬 인식 서버를 실행하지 않는다.

## 무료량 보호 범위

- 인증·동일 출처·파일 형식 검사 후 원자적 DB 예약으로 모든 사이트 사용자 합산 월 한도를 제한한다. 한국 시간 달력 월 기준이다.
- 실패·타임아웃·불완전 결과도 사용량에 포함한다. 공급자가 이미 처리했을 수 있으므로 횟수를 돌려주지 않는다. 자동 재시도하지 않는다.
- 콘솔·다른 앱·다른 로컬 DB의 호출 수는 이 DB에 집계되지 않는다. 같은 계정의 무료량을 별도로 사용하면 사이트 한도를 그만큼 낮춰야 한다. 로컬/운영 카운터는 별개다.
- API Gateway 등 다른 서비스 비용까지 제한하는 기능은 아니다. 무료량을 다른 용도로 쓰지 않는 전용 구성이 전제다.
- 원본·응답·키를 OCR 서버 로그에 남기지 않는다. 일정 저장 전에는 일정과 R2 원본을 생성하지 않는다.

확인 항목: 전체 행 수, 한 줄 일정표, 김정미A 같은 이름 접미사, 영문 동 표기, 번지·전화번호·방문 시간, 주소와 메모 셀 분리. 원본과 직접 비교하여 누락·추가·문자 오류를 기록한다. 실 API는 합성 일정표로 검증했으며 실제 현장 사진 정확도는 별도 확인 필요하다.
