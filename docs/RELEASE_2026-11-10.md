## 운영 배포 상태: 무료 D1 한도로 대기

2026-11-10 운영 DB 사전 조회와 마이그레이션 목록 조회를 시도했으나 Cloudflare가 `7500` 오류로 거부했습니다. 응답은 D1 무료 일일 행 조회 한도를 초과했다고 명시했습니다. 이 한도는 앱 테스트가 사용하는 별도 로컬 DB와 구분됩니다. Windows CLI의 종료 시 assertion 메시지는 같은 실패에 부수적으로 발생했으며, 원래 오류 원인은 Cloudflare의 조회 거부입니다.

이 상태에서 새 Worker만 배포하면 아직 적용하지 못한 `0021_folder_operations.sql`의 열·테이블을 조회해 기존 화면까지 실패할 수 있으므로 운영 마이그레이션·Worker 배포를 진행하지 않았습니다. 운영 자료·관리자 자격 증명·요금제는 변경하지 않았습니다. 운영 전후 자료 수와 신규 기능 검증도 DB 조회가 재개된 뒤 진행해야 합니다.

Cloudflare는 무료 일일 한도를 UTC 00:00에 초기화합니다. 다음 재개 시각은 **2026-11-11 오전 9시(한국 시간)**입니다. 한도가 초과된 동안에는 기존 서비스의 D1 조회도 오류를 반환할 수 있습니다. [Cloudflare D1 공식 한도·초기화 설명](https://developers.cloudflare.com/d1/platform/pricing/#definitions)

## 배포 재개

1. Git 변경 여부와 제품 소스 SHA를 확인하고 달라졌다면 전체 검증을 다시 수행합니다.
2. 운영 DB 조회 재개를 확인하고 자료 수·관리자 계정 지문·비밀키 이름을 비공개 기록으로 보관합니다. 과거 2026-10-14 자료 수를 현재 기준으로 사용하지 않습니다.
3. `node scripts/deploy-cloudflare.mjs`로 검증·원격 마이그레이션·Worker 배포를 순서대로 실행합니다. 기존 비밀키와 공용 owner를 유지합니다.
4. 새 기능의 읽기·잘못된 변경 거부, 기존 로그인·목록·검색·개인 기록, 배포 번들의 일치 여부와 자료 보존을 확인하고 실제 Worker 버전을 이 문서에 기록합니다.
