## 반영한 내용

1. **업로드 신뢰성**: 파일별 작업 ID와 SHA-256, DB claim/fencing으로 응답 유실 재시도 중복을 방지합니다. 삭제된 작업 재전송은 거부합니다. 전송 제한 시간과 중단, 미전송 재시도를 제공합니다. 폴더 삭제 중 저장은 막고 오래된 미완료 업로드 임시 파일을 정리할 수 있습니다.
2. **여러 기기 수정**: 일정 revision 확인으로 상태·비고 덮어쓰기를 막습니다. 충돌 화면에서 다른 기기 값과 작성 중인 내용을 비교하고, 수정한 항목만 합쳐 검토할 수 있습니다.
3. **기기 임시 보관**: IndexedDB에 원본과 작업 ID를 최대 200장/512MiB 보관합니다. 저장 확인 후 제거하고 새로고침 후 복구합니다. 기기 보관 실패는 경고하며 직접 업로드와 촬영 원본 다운로드를 제공합니다.
4. **사용량**: 기본 8GB를 유지하며 관리자 키·비용 확인으로 앱 저장 상한을 바꿀 수 있습니다. 80% 경고, 최근 7일 업로드 기준 예상 잔여 일수를 표시합니다. Cloudflare 요금제나 계정 전체 과금 한도를 바꾸지 않습니다.
5. **자료 보존**: 별도 전체 백업에 일정·상태·비고·사진·일정표·도면 초안을 포함합니다. 파일별 해시와 디스크 저장 내용을 검증하고 중단 후 재개합니다. 복원은 임시 저장 후 별도 구역에 원자적으로 공개하며 기존 자료를 덮어쓰지 않습니다. 취소·재시도·미완료 정리를 지원합니다.
6. **대량 조회·다운로드**: 폴더 통계를 DB 트리거로 유지하고 사진은 60장씩 읽습니다. 일반 사진 ZIP은 현장 사진만 포함하며 200MB 분할과 목록 변경 검증을 제공합니다.
7. **보안**: ZIP 티켓 발급은 동일 Origin POST만 허용하고 실제 원본 요청 때 읽기 사용량을 차감합니다. 일정표 미리보기는 JPEG/PNG/WEBP 바이트 확인 및 고정 이미지 형식으로 제한하고 활성 문서 링크를 제거했습니다. 실제 연락처 seed를 제거했으며 기존 DB는 보존합니다.
8. **운영 절차**: 앱 린트 오류, 옛 인증 설명, Python/UTF-8 실행 문제를 정리했습니다. npm run verify를 배포 공통 게이트로 연결하고 소스 해시·Git revision·검증 시각 및 향후 배포 버전 기록을 추가했습니다.
